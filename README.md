## 코드 실행

Python 3.11 이상에서 `코드` 디렉터리를 실행 루트로 사용합니다.

```bash
git clone https://github.com/bigeatman/money.git
cd money/코드
python -m money.cli init
```

기존 설치의 설정과 장부를 새로 초기화하지 않습니다. 상세 설정과 Termux 실행은 [코드 안내](코드/README.md)를 확인합니다.

```bash
cd 코드
python -m unittest discover -s tests -v
```

## 현재 반영 상태

- 실행기 V6: 미국 모의매수에서 미지원 `ust31490` 호출을 제거하고 `ust21110` 현금과 `ust21050` 미체결로 매수 가능 수량을 보수적으로 계산합니다. [변경 설명](코드/docs/us_cash_v6.md)
- 전략 v2.0: 단기투자로 전환하고 정규장 매시간 전체 종목의 신규 매수 가능성과 모든 보유 종목의 전망을 재평가합니다.
- 보유 전망에 따라 목표 매도가를 상향·하향하거나 청산하며, 목표 변경은 `REPRICE`로 실제 주문 상태와 일치시킵니다.
- 마감·거래일 변경 강제청산과 고정 보유 기간 제한은 없습니다. 다음 거래일 주문 관리에는 검증한 새 세션이 필요합니다.
- V7 전 종목 수집기: 국내·미국 전체 종목 목록을 먼저 확보하고 정책 제외, 공통 시세·거래량 검증, 가격·활동 신호와 대기 목록을 제공합니다. 페이지 누락과 N/E/U/V/D를 검증하며 임의의 상위 종목에서 시작하지 않습니다. [수집·조회 절차](코드/docs/market_scanner.md)
- 수집은 정규장 매시간 백그라운드에서 수행합니다. 전수 확보·선정이 끝나지 않으면 신규 매수를 보류하고 '선정 작업 미완료'로 보고하며, 기존 보유 관리와 매도·목표가 변경은 계속합니다. 프로그램의 신호 분류만으로 자동 매수하지 않습니다.
- AI 재평가는 외부 예약의 지시로 수행합니다. 소스 설치만으로 예약이 생성되거나 활성화되지는 않습니다.
- 기존 `20261015_국내장_모의투자_일일보고서.txt`는 사용자 요청으로 저장소에서 삭제했습니다.

실제 API 키, 토큰, 계좌번호, 개인 실행 설정과 SQLite 장부는 저장소에 포함하지 않습니다. Git 업로드는 휴대폰 프로그램의 원격 재배포를 뜻하지 않습니다.
