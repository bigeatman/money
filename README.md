## 코드 실행

Python 3.11 이상에서 `코드` 디렉터리를 실행 루트로 사용합니다.

```bash
git clone https://github.com/bigeatman/money.git
cd money/코드
python -m money.cli init
```

상세 설정과 Termux 실행은 [코드 안내](코드/README.md)를 확인합니다.

```bash
cd 코드
python -m unittest discover -s tests -v
```

## 현재 반영 상태

- V5: 마감 시각·거래일 변경에 따른 강제청산 제거, 익일 보유 가능.
- 목표가 매도·명시적 SELL 유지. 다음 거래일 주문 관리에는 새 거래일 세션 갱신이 필요합니다.
- AI 정기 재평가 예약은 현재 비활성입니다. 실행기가 매수 논리 무효를 독자 판단하는 것은 아닙니다.
- ETF 상품별 비용·세금 처리는 일일 보고서에 남은 문제로 기록돼 있으며, 이번 업로드에서 비용 설정이나 장부를 변경하지 않았습니다.

실제 API 키, 토큰, 계좌번호, 개인 실행 설정과 SQLite 장부는 저장소에 포함하지 않습니다. Git 업로드는 휴대폰 프로그램의 원격 재배포를 뜻하지 않습니다.
