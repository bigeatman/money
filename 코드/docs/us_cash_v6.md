# V6 미국 모의매수 현금 검증

2026-10-15 미국장 실행에서 모의서버가 `ust31490`을 `RC9000: 모의투자에서는 해당업무가 제공되지 않습니다`로 거절했다. V5는 이 조회를 필수로 호출해 증권사 주문 전 중단됐다.

V6는 모의 전용 어댑터에서 지원이 확인된 `ust21110`과 `ust21050`으로 현금 한도를 보수적으로 계산한다. 이는 증권사가 반환하는 종목별 무미수 수량과 동일한 값이라고 주장하지 않는다. 종목별 거래 가능 여부의 최종 판단은 모의 증권사의 실제 주문 접수 결과다.

- USD 예수금·출금가능액·주문가능액 중 최솟값을 현금 상한으로 쓴다. 미결제 매도대금/다른 통화 자동환전 한도를 추가하지 않는다.
- 원화 및 USD 미수금·대여금, USD 선물 담보가 0인지 확인한다. 필수 필드가 없거나 숫자가 잘못되면 차단한다.
- 수동 주문을 포함한 미국 미체결 매수의 잔여 지정가 금액과 설정 매수 수수료를 차감한다. 이미 차감된 돈을 다시 예약할 수 있어 실제 가능액보다 작을 수 있다.
- 시장가 등 비용 상한을 확정할 수 없는 미체결 매수, 불명확한 주문 잔량, 불완전한 연속조회는 신규 매수를 차단한다.
- 새 매수 수수료를 포함해 정수 수량을 계산하며 기존 공통 100만원 전략 예산·현재 환율·체결 확인·미확정 주문 차단을 유지한다.
- 조회 후 호가가 30초를 넘기거나 지시가 만료되면 주문하지 않는다.

`execution_capabilities.adapter_version`은 `us-demo-v6`, 현금 방식은 `conservative_usd_cash`다. 인증된 로컬 `/diagnostics`의 `part=buying_power`는 주문 없이 이 조회 경로를 확인한다.

## 휴대폰 적용

제공한 `money_fix_20261016_v6.py`를 Download 폴더에 저장한 뒤:

```bash
python /storage/emulated/0/Download/money_fix_20261016_v6.py
```

기본 대상은 `~/money-work/money`다. 다른 경로는 첫 인자로 지정한다. 알려진 V5/V6 소스만 변경하며 설정·키·SQLite 장부를 재생성하지 않는다. 유효한 대기/미확정 매수 주문이 있으면 자동 적용을 멈춘다. 종료 시 장부 저장을 기다리고 소스를 백업한 뒤 수정·자체 테스트·재시작을 수행한다. 소스 검증 또는 시작 확인 실패 시 이전 소스로 복원한다. 재시작 후 실시간 계좌/현금 조회 실패는 코드 롤백 사유가 아니며, 적용 완료와 조회 실패를 분리해 출력한다.

이 파일은 매매 지시를 제출하지 않는다. 철회된 OPK 계획도 재개하지 않는다. 완료 출력을 대화에 전달한 뒤 최신 시세로 새 매매 판단이 필요하다. 마감/거래일 변경 강제청산 제거와 기존 익일 보유 정책은 그대로다.

## 검증 범위

로컬 합성 데이터로 수수료 경계, 현금 부족, 미확정 매수, 수동 주문 예약, 중복 주문, 누락/잘못된 응답, 부채, 지연 시세, 예산, 무주문 진단을 시험한다. 휴대폰 적용 후 실제 주문·체결 성공은 별도 검증 대상이다.
