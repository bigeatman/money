# 단기투자 매시간 운용 절차

## 적용 범위와 역할

현재 기준은 전략 v2.0과 사용자의 최신 지시다. 국내·미국 키움 모의계좌에 공통 최초 원금 1,000,000원 장부를 사용하며 최대 동시 10종목이다. 현재 전략 현금과 모든 미체결 예약을 반영한다. 계좌 전체 모의 현금을 전략 예산으로 사용하지 않는다. 일반 현금 주식만 신규 매수하며 수동 보유분은 거래하지 않는다.

Work가 전체 시장 선정, 투자 가설, 수량과 매수 상한, 목표가와 청산을 판단한다. Python은 계좌·지정 종목 데이터 공급과 주문 실행을 맡는다. 실행기에 전 종목 스캐너나 가격 예측 전략이 내장돼 있다고 설명하지 않는다.

운용 목적은 단기투자다. 당일 또는 일괄 1~3거래일 보유 제한을 두지 않는다. 마감과 거래일 변경만으로 강제청산하지 않는다. 예상 투자 전개 기간과 가설의 무효 조건을 기록하고 매시간 재평가한다. 고정 손실 금액·손실률이나 매 회차 매수 의무를 추가하지 않는다.

## 1. 거래일·계좌·주문 대조

공식 거래소 자료로 현지 거래일과 실제 정규장 개장·마감, 휴장·조기 종료·지연 개장을 확인한다. 정규장 밖에서 지연 실행된 회차는 새 주문 없이 상태와 사유를 기록한다. 이번 시간별 예약에서 장전 매수 기능을 임의로 사용하지 않는다.

`get_trading_snapshot`과 `get_execution_status`를 실제 호출해 현금, 보유 수량, 미체결, 직전 이후 체결, 비용과 환율을 확인한다. 수량 0인 과거 보유 기록은 현재 보유가 아니다. 누락·null을 0으로 바꾸지 않는다. 계좌 불완전, 동기화 오류, 일시 중단 또는 주문 결과 불확정이면 신규 매수를 보류한다. 접수 여부가 불확정인 주문을 재전송하지 않는다.

미국 V6는 체결 `ust21510`, 미체결 `ust21050`, 현금 `ust21110`과 `conservative_usd_cash` 방식을 사용한다. 미지원 `ust31490`·`ust21180` 호출로 복귀하지 않는다. 현금 수량 계산은 증권사의 종목별 무미수 가능 수량을 직접 조회한 값과 구분한다. 당일 전용 체결 조회의 거래일·원본 시각을 확인하고 전일 미해결 주문은 별도로 대조한다.

## 2. 전체 시장에서 신규 후보 선정

장전 또는 장중의 매 회차 대상 시장 전체 종목 목록과 기준일, 거래소와 자산 유형 범위를 확정한다. 전 종목의 공통 기본 데이터를 확보하고 코드 매핑, 페이지 완결성, 원본 시각·지연·누락을 검증한다. 기본 snapshot, 기존 관찰 목록, 뉴스·급등 순위를 전체 시장으로 취급하지 않는다. 호출당 조회 한도는 배치 크기이며 후보 수의 상한이 아니다.

전체 N·정책 제외 E·대상 U·입력 확인 V·미확보 D를 기록해 N=E+U, U=V+D를 맞춘다. 동일한 사전 규칙을 적용한 뒤 활동 증가 또는 가격 전환 또는 새 사건 경로의 합집합을 상세 비교한다. 단계별 입력·통과·규칙 제외·조건 대기·자료 부족 및 상세 미검토 수와 종목별 관측값·사유를 남긴다.

전수 확보·선정이 끝나지 않았으면 '선정 작업 미완료'로 보고하고 이번 선정에 근거한 신규 매수를 확정하지 않는다. 자료 접근 실패나 미검토를 조건 미달로 바꾸거나 '살 종목 없음'이라고 결론 내리지 않는다. 확인 가능한 기존 보유와 미체결 관리는 계속한다.

## 3. 현재 가격에서 매수 가능성 평가

현재 가격에서 단기 상승을 설명할 사실·사건 또는 가격 전환, 일봉과 완료된 60분 또는 30분 흐름, 동시간 참여와 시장·업종 대비 흐름을 비교한다. 사건은 원문과 최초 공개 시각 및 이미 반영된 가격 움직임을 확인한다. 5분봉은 실행 보조로 사용하며 모든 매수에 돌파·재시험을 강제하지 않는다. 옛 점수 조합을 자동 매수 문턱으로 쓰지 않는다.

반대 근거, 목표 구간과 도달 경로, 비용 차감 여지, 예상 전개 기간과 가설 무효 조건을 함께 확인한다. 과거 고가와 현재가의 차이 자체를 재상승 근거로 쓰지 않는다. RVOL 분모·승률·기대수익을 만들지 않는다.

조건이 갖춰진 후보는 현재 현금과 계좌 제약을 반영한 정수 수량, 현재 유효 가격 범위, 매수 상한과 최초 목표가를 정해 BUY를 실제 제출한다. 조건 대기에는 필요한 신호와 지시 만료를 기록한다. 매수 근거가 사라진 미체결은 상태를 확인해 취소한다.

## 4. 보유 전 종목 재평가

신규 선정 결과와 별개로 모든 전략 보유의 최초 가설과 새 사실, 앞으로의 상승·하락 전망을 비교한다.

| 재평가 | 행동 |
| --- | --- |
| 강화 | 기존 목표 위의 상승 경로가 설명되면 목표 상향 |
| 유지 | 유효한 기존 목표와 매도 주문 유지 |
| 약화 | 목표 하향 또는 청산 결정 |
| 무효 | 청산 판단을 실행 지시로 반영 |
| 자료 부족 | 누락과 현재 주문 상태를 기록하고 확인 가능한 관리를 계속 |

직전·새 목표와 변경 근거를 남긴다. 매수가를 목표 하향의 하한으로 고정하거나 근거 없이 목표를 계속 높이지 않는다.

## 5. 매도 예약 갱신과 청산

목표 변경이 필요하면 지원되는 REPRICE로 실제 반영한다. 변경 직전의 현재 보유, 기존 매도 주문번호·가격·미체결 잔량과 부분 체결을 확인한다. 취소·정정·재접수는 실행기가 지원하는 한 경로로 처리하고 별도 CANCEL/SELL을 겹쳐 제출하지 않는다.

취소 접수와 취소 완료를 구분한다. 취소 사이의 추가 체결을 반영한 남은 수량으로 새 주문을 확인한다. 새 목표·주문번호·수량·접수·체결·잔량을 대조한다. 취소 실패면 기존 주문이 살아 있을 수 있으므로 중복 재전송하지 않는다. 취소 성공 후 재접수 실패는 매도 예약 공백으로 기록해 복구 판단을 우선한다. 전량 체결된 종목의 목표를 갱신하지 않는다.

전망·목표가가 같고 기존 주문이 유효하면 불필요한 취소·재주문을 하지 않는다. 지정가 매도는 자동 손절이 아니다. 즉시 정리가 필요하면 지원되는 SELL을 사용하고 기존 예약과 수량 중복을 막는다. SELL quantity=0은 프로그램 보유 전량이다.

## 6. 실제 지시와 결과 확인

`submit_trading_plan`에 고유 plan_id, 실제 생성·만료 시각, 공식 확인한 session 개장·마감과 HTTPS calendar_sources를 포함한다. 지시는 정규장 안의 짧은 유효기간으로 두며 생성 후 최대 60분, 마감 이후로 연장하지 않는다. 지시 만료와 보유 기간은 별개다.

제출 후 `get_execution_status`로 접수·미체결·부분/전량 체결·취소·실패·불확정을 구분한다. 문장만으로 매수나 목표 변경을 완료했다고 하지 않는다. HOLD 처리 건수를 매매나 체결 실적처럼 보고하지 않는다.

## 7. 익일 보유와 다음 거래일 주문

익일 보유와 매도 주문의 익일 유효성을 구분한다. 새 거래일에는 공식 달력으로 검증한 session을 갱신하고 전일 체결·취소·만료와 현재 보유를 대조한다. 원금·현금을 매일 초기화하지 않는다.

국내 DAY 주문은 원 주문일의 체결내역을 먼저 반영하고 실행기의 만료 확인 절차 후 잔량의 목표 주문을 재등록한다. 내역 누락을 단순 만료로 추정하지 않는다. 미국 전일 미확정 주문은 당일 전용 API만으로 해결했다고 간주하지 않으며, 증권사 대조 전 해당 시장 실행을 보류한다.

## 8. 시간별 회차와 기록

| 시장 | 기본 회차 | 시간대 |
| --- | --- | --- |
| 국내 | 09:00부터 15:00까지 매시간 | Asia/Seoul |
| 미국 | 09:30부터 15:30까지 매시간 | America/New_York |

각 회차의 실제 공식 세션을 우선한다. 휴장·조기 종료·지연 개장·예약 지연으로 장 밖이면 새 주문하지 않는다. 미국 일정은 뉴욕 시간대를 사용해 서머타임을 반영한다. 기본 신규 매수 마감과 미체결 매수 취소 버퍼는 실행기의 기존 설정을 따르며, 보유분을 마감 때문에 청산하는 시각이 아니다.

시장·현지 거래일별 기록에 예정/실제 실행 시각과 원본 시세 시각, 전체 수와 단계별 결과·누락·미검토, 신규 매수·보류 근거, 모든 보유의 전망과 목표 변경, 실제 주문·취소·재접수·체결·잔량·현금·비용 포함 손익과 다음 확인 사항을 남긴다. 전 종목 수집 기능이 확인되지 않았으면 그 사실을 먼저 보고한다. 거래가 없어도 기록하며 저장 실패를 성공으로 표시하지 않는다.
