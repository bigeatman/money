# 종목 선정 전략

[20261016_단기투자_전략.docx](20261016_단기투자_전략.docx)가 현재 전략 v2.0입니다. 기존 단타 문서를 갱신해 단기투자, 매시간 전 종목 점검, 모든 보유의 전망 재평가와 목표 매도 주문 갱신을 반영했습니다.

[운용절차](운용절차.md)는 이 전략을 실제 계좌 조회와 주문 지시에 적용하는 절차입니다.

- 전체 시장 목록과 공통 데이터를 먼저 확보하고 동일한 규칙으로 단계별로 좁힙니다. 기존 관찰 종목이나 뉴스 순위로 출발 집합을 대신하지 않습니다.
- 전수 입력·검토 미완료는 '살 종목 없음'과 구분합니다. 신규 선정을 끝내지 못해도 확인 가능한 기존 보유 관리는 계속합니다.
- 보유 종목은 매시간 전망 강화·유지·약화·무효·자료 부족으로 재평가하고 목표 상향·유지·하향 또는 청산을 결정합니다.
- 목표 변경은 취소·정정·재접수와 부분 체결을 확인해 남은 수량에 반영합니다.
- 당일 청산과 일괄 1~3거래일 보유 제한, 옛 점수 조합과 5분봉 돌파·재시험의 일괄 진입 조건은 적용하지 않습니다.

이 문서 갱신은 전 종목 데이터 수집 기능의 구현 완료나 전략의 수익성 검증을 뜻하지 않습니다.
